Factory built

Element houses, built indoors to millimetre accuracy

Exterior, interior, ceiling, roof and terrace elements — produced in a controlled factory environment, free from the restrictions that come with building on an open site.

How it works

Quality that starts indoors

Our Kiili factory produces exterior walls, interior partitions, inserted ceilings, roof and terrace elements — all built indoors, in a specific controlled environment. That excludes the damage and discomfort that rain, snow, wind and temperature swings can cause during an open-air build.

Because every element is produced with millimetre accuracy, on-site assembly is fast and precise, and the finished building performs exactly as designed.

Unlike modular construction, element building carries no real restriction on size or architectural complexity — large buildings, and even full apartment houses, can be built this way.
