Modular

Modules finished in the factory, joined on site

More than 90% of the work happens indoors, in a weatherproof, controlled environment — modules arrive on site already finished inside and out.

How it works

An innovative, flexible construction system

EstNor modular buildings offer an innovative, flexible approach and the best possible construction outcome. Each module consists of floor, wall and roof elements assembled together in the factory, finished inside and out, with roofing installed.

All window and door openings are fitted and finished before the module leaves the factory. We also carry out all special work — electrical, plumbing, ventilation and heating — while the module is still indoors.

Modules can be joined together to create larger buildings that meet the specific space needs of each customer, from a single private house to a full apartment block.

Open building system

Contributing to 369 Pattern Buildings

EstNor contributes to 369 Pattern Buildings — an open-source, mass-customisable industrial building system for wooden buildings — helping push modular construction toward smarter, more sustainable defaults.
