# Serial-renovation reference buildings

One folder per renovated apartment building, shown as photo albums in
the **Serial Renovation page's "Renovation references" section**
(`serial-renovation/index.php#references`). Same layout and rules as
`../references/README.md` — `<lang>.txt` files plus any number of
photos, folder-number ordering with the highest number first — read the
README there for the details.

This is a **separate collection from `../references/`**, on purpose:

- The general References page shows the renovation work as *one*
  combined album (`../references/<NN>-tehaseline-renoveerimine/`), so a
  visitor who only browses References still finds it.
- This folder splits the same work *per building*, for the Serial
  Renovation page only. Nothing here appears on the References page or
  the homepage teaser.

So a new renovated building goes in **both** places: add its photos to
the combined album over there, and give it its own numbered folder here.

Photo `02-…-enne-parast.jpg` in each folder is the before/after
composite from the old site's "Tehtud renoveerimisprojektid" page; it's
second, not first, because the card cover is always the first photo and
a 2.4:1 composite crops badly there.
